3. **[استقرار و خودکارسازی (Deployment)](deployment.md)**: نحوه کارکرد GitHub Actions و Hugging Face.
4. **[راهنمای نصب و اجرا (Setup)](setup.md)**: چگونگی راه‌اندازی پروژه در محیط محلی.
