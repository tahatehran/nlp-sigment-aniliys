# آموزش صفر تا صد و تحلیل خط‌به‌خط کدهای پروژه

در این بخش، تمام اجزای پروژه را به صورت آموزشی و از پایه بررسی می‌کنیم. این راهنما برای کسانی که می‌خواهند منطق پشت سیستم را درک کنند یا آن را ارائه دهند، طراحی شده است.

---

## ۱. فایل `prepare_data.py` (گردآوری و آماده‌سازی داده‌ها)

این فایل وظیفه دارد داده‌های خام را از اینترنت (Hugging Face) جمع‌آوری کرده و یک دیتابیس محلی برای جستجوی سریع بسازد.

### وارد کردن کتابخانه‌ها:
```python
import pandas as pd # برای کار با جداول داده
from datasets import load_dataset # برای دانلود مستقیم دیتاست‌های NLP
import re # برای پاکسازی متن با استفاده از عبارات باقاعده
import os # برای عملیات فایل و پوشه
import sys # برای کنترل خروج از برنامه
import numpy as np # برای عملیات ریاضی روی بردارها
from sentence_transformers import SentenceTransformer # برای تبدیل متن به بردار (Embedding)
import faiss # کتابخانه فیسبوک برای جستجوی بسیار سریع در میان میلیون‌ها بردار
```

### تابع `clean_text`:
این تابع کاراکترهای اضافه و فضاهای خالی تکراری را حذف می‌کند تا متن ورودی تمیز شود.
```python
def clean_text(text):
    if not isinstance(text, str):
        return ""
    text = re.sub(r'\s+', ' ', text).strip()
    return text
```

### تابع `get_samples_from_stream`:
این تابع از قابلیت **Streaming** استفاده می‌کند. یعنی به جای دانلود فایل‌های چند گیگابایتی، نظرها را یکی‌یکی از اینترنت می‌خواند تا رم سیستم پر نشود.
- ستون‌های احتمالی مانند `text`, `comment`, `body` را بررسی می‌کند.
- فقط نظراتی که بیش از ۲۵ کاراکتر دارند را انتخاب می‌کند (برای حفظ کیفیت).

### تابع `fetch_all_data`:
این تابع ۴ منبع مختلف (دیتاست‌های معتبر دیجی‌کالا) را ترکیب می‌کند تا تنوع داده‌ها بالا برود. در نهایت ۲۰۰۰ نمونه متعادل (از هر منبع ۵۰۰ تا) گلچین می‌کند.

### تابع `generate_faiss_index`:
مهم‌ترین بخش برای سرعت سیستم:
1. تمام ۲۰۰۰ جمله را به مدل `paraphrase-multilingual-MiniLM-L12-v2` می‌دهد.
2. مدل برای هر جمله یک بردار (لیستی از اعداد) تولید می‌کند که معنای آن جمله را نشان می‌دهد.
3. این بردارها در یک "ایندکس" (Index) ذخیره می‌شوند که اجازه می‌دهد در کسری از ثانیه، شبیه‌ترین جملات پیدا شوند.

## ۲. فایل `processor.py` (هسته پردازشی و معماری RAG)

این فایل کلاس `SentimentRAG` را تعریف می‌کند که تمام مدل‌های هوش مصنوعی را مدیریت می‌کند.

### الگوی Singleton:
ما از متد `__new__` استفاده می‌کنیم تا مطمئن شویم در طول کل برنامه، فقط **یکبار** مدل‌ها در حافظه لود می‌شوند. این کار باعث صرفه‌جویی شدید در مصرف رم می‌شود.

### متد `__init__`:
در اینجا سه مدل اصلی لود می‌شوند:
1. **BERT Sentiment** (`nlptown/bert-base-multilingual-uncased-sentiment`): برای تشخیص ستاره (۱ تا ۵).
2. **Sentence Transformer** (`paraphrase-multilingual-MiniLM-L12-v2`): برای تبدیل ورودی کاربر به بردار جهت جستجو در FAISS.
3. **Persian GPT-2** (`HooshvareLab/gpt2-fa-comment`): برای تولید متن و توضیح دلیل تحلیل.

### متد `get_sentiment`:
متن کاربر را به مدل BERT می‌دهد و دو خروجی می‌گیرد: عدد ستاره و میزان اطمینان مدل.

### متد `retrieve_similar` (بخش Retrieval در RAG):
ورودی کاربر را به بردار تبدیل کرده و در ایندکس FAISS جستجو می‌کند تا ۲ نظر مشابه را از دیتابیس ۲۰۰۰ تایی پیدا کند.

### متد `generate_explanation` (بخش Generation در RAG):
این متد جادوی اصلی پروژه است:
1. متن کاربر + نظرات مشابه پیدا شده را ترکیب می‌کند.
2. یک "پرامپت" (Prompt) تخصصی می‌سازد.
3. مدل GPT-2 با دیدن این اطلاعات، یک دلیل منطقی تولید می‌کند که چرا این نظر مثبت یا منفی است.

## ۳. فایل `app.py` (رابط کاربری و داشبورد)

این فایل با استفاده از `Streamlit` یک سایت تعاملی می‌سازد.

### تنظیمات ظاهری (CSS):
ما از استایل‌های سفارشی برای راست‌چین کردن (RTL) متن‌ها و استفاده از فونت فارسی **Vazirmatn** استفاده کرده‌ایم تا تجربه کاربری ایرانی بهتری ایجاد شود.

### بخش تحلیل زنده:
کاربر متن را وارد می‌کند، دکمه را می‌زند و `processor.py` فراخوانی می‌شود. نتیجه با انیمیشن‌های زیبا و آیکون‌های رنگی نمایش داده می‌شود.

### بخش آمار و ارقام (Dashboard):
در این بخش، نمودارهایی از توزیع احساسات در دیتابیس ۲۰۰۰ تایی نمایش داده می‌شود تا کاربر دید کلی نسبت به نظرات دیجی‌کالا پیدا کند.

## خلاصه جریان کار (Workflow)
۱. **ورودی**: کاربر می‌گوید "گوشی خوبیه ولی زود داغ می‌کنه".
۲. **بازیابی (Retrieve)**: سیستم نظرات مشابهی که درباره داغ کردن یا کیفیت گوشی هستند را از FAISS پیدا می‌کند.
۳. **تحلیل**: مدل BERT تشخیص می‌دهد که این نظر ۳ یا ۴ ستاره (متوسط رو به بالا) است.
۴. **تولید (Generate)**: مدل GPT-2 با ترکیب نظر کاربر و شواهد پیدا شده، توضیح می‌دهد: "به دلیل اشاره به کیفیت خوب در کنار مشکل فنی دما، نظر در دسته متوسط طبقه‌بندی شد".
