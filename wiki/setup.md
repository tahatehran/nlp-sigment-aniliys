# راهنمای نصب و اجرا

اگر می‌خواهید این پروژه را روی سیستم خودتان اجرا کنید:

### پیش‌نیازها:
- Python 3.10+
- نصب کتابخانه‌های مورد نیاز:
```bash
pip install -r requirements.txt
```

### مراحل اجرا:
1. **آماده‌سازی داده‌ها**:
   ابتدا باید دیتابیس محلی ساخته شود:
   ```bash
   python prepare_data.py
   ```
2. **اجرای اپلیکیشن**:
   ```bash
   streamlit run app.py
   ```

### اجرا در Google Colab:
اگر کارت گرافیک قوی ندارید، فایل موجود در پوشه `colab/` را در گوگل کولب باز کنید. این نسخه به صورت تعاملی و متنی اجرا می‌شود و نیاز به نصب هیچ چیز روی سیستم شما ندارد.
