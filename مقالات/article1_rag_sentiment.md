# RAG-Enhanced Sentiment Analysis System Using Transformer Models and FAISS for Customer Review Analysis

**نویسنده:** Maideen Fargana M.
**لینک:** https://doi.org/10.22214/ijraset.2025.76657

## خلاصه
این مقاله به بررسی استفاده از معماری RAG برای بهبود دقت تحلیل احساسات در نظرات مشتریان می‌پردازد. با استفاده از مدل‌های ترنسفورمر و کتابخانه FAISS، این سیستم قادر است نظرات مشابه را بازیابی کرده و از آن‌ها برای ارائه تحلیل‌های دقیق‌تر استفاده کند. این رویکرد به ویژه در پلتفرم‌های تجارت الکترونیک برای درک بهتر بازخورد مشتریان کاربرد دارد.
